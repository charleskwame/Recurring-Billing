Backend provider payloads

// Signed Capture Context request
  {
    "targetOrigins": ["<frontend-origin>"],
    "clientVersion": "1.0",
    "country": "US",
    "locale": "en_US",
    "data": { "orderInformation": { "amountDetails": { "totalAmount": "50.00", "currency": "USD" } } }
  }

  // Signed follow-on subscription request
  {
    "clientReferenceInformation": { "code": "subscription_<transactionId>" },
    "subscriptionInformation": {
      "planId": "<recurring-plan-id>",
      "name": "Weekly 50 Test",
      "startDate": "2026-09-29T12:00:00Z"
    }
  }

  1. 01

    Choose a plan

    The plan button sends its data-plan-key to the backend.

    button.dataset.planKey
axios.post("/checkout-session", paymentPayload(planKey))
  2. 02

    Create the checkout session

    The backend signs a request to CyberSource and returns a Capture Context token.

    await axios.post(url, checkoutPayload, { timeout: 10000 })
  3. 03

    Mount Unified Checkout

    The frontend loads the CyberSource SDK, mounts the payment UI, and waits for the payment result.

    const client = await window.VAS.UnifiedCheckout(captureContext)
const result = await checkout.mount({...})
  4. 04

    Start recurring billing

    The backend reads the transaction ID and creates the follow-on subscription, retrying temporary failures.

    await axios.post("/activate-recurring-billing", { result, planKey })
POST /rbs/v1/subscriptions/follow-ons/{transactionId}
  5. 05

    Wire the plan buttons

    The page loads Axios and the frontend module, then registers getSessionContext for every plan button.

    planButtons.forEach((button) =>
  button.addEventListener("click", getSessionContext))
  6. 06

    Validate the plan on the backend

    The backend rejects missing CyberSource configuration or an unknown plan before calling the payment provider.

    const plan = getPlan(req.body?.planKey)
if (!plan) return res.status(400).json({ error: "A valid subscription plan is required." })
  7. 07

    Apply the trusted plan amount

    The backend removes planKey and replaces the client amount with the server-side plan amount and USD currency.

    checkoutPayload.data.orderInformation.amountDetails = {
  totalAmount: plan.amount,
  currency: "USD"
}
  8. 08

    Create the Capture Context

    The backend signs the request with CyberSource credentials. This provider call has a 10-second Axios timeout.

    const headers = createHeaders(...)
const response = await axios.post(url, checkoutPayload, {
  headers,
  timeout: 10000
})
  9. 09

    Read the Capture Context

    The frontend decodes the token to find the CyberSource client library URL and integrity value, while passing the original token unchanged to checkout. 

    const decoded = decodeJwtPayload(captureContext)
const contextData = decoded?.ctx?.[0]?.data
const { clientLibrary, clientLibraryIntegrity } = contextData
  10. 10

    Load and mount Unified Checkout

    The browser loads the provider SDK, renders payment selection and the payment screen, and waits for the completed payment result.

    await loadCyberSourceSdk(clientLibrary, clientLibraryIntegrity)
const client = await window.VAS.UnifiedCheckout(captureContext)
const checkout = await client.createCheckout({ autoProcessing: true })
const result = await checkout.mount({
  paymentSelection: "#buttonPaymentListContainer",
  paymentScreen: "#embeddedPaymentContainer"
})
  11. 11

    Extract the transaction ID

    The backend decodes the payment-result JWT, reads its transaction ID, and looks up the same validated recurring plan.

    const decoded = decodeJwtPayload(req.body?.result)
const transactionId = decoded?.id
const plan = getPlan(req.body?.planKey)
  12. 12

    Create, retry, and finish

    The backend links the subscription to the completed transaction, retries temporary 502/503/504 failures up to four total attempts, and returns the result. The frontend displays success or the error, then destroys the checkout objects. 

    POST /rbs/v1/subscriptions/follow-ons/{transactionId}
FOLLOW_ON_RETRY_DELAYS_MS = [300, 500, 1000]
checkout.destroy(); client.destroy();
